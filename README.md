### Irish Art Gallery Website

An interactive web platform dedicated to showcasing and celebrating historical Irish art. The website features a curated historical timeline alongside various community and informational pages currently in active development. 

### Current Features & Progress

* **Historical Art Timeline (Completed):** An interactive timeline on the homepage (index.html) highlighting key eras, movements, and masterpieces of historical Irish art.
* **Contact Page (In progress):** A dedicated contact page containing a functional user inquiry form.
* **Blog Section (In Progress ):** A future hub for articles, artist spotlights, and exhibition news.
* **About Page (In Progress ):** An unfinished section detailing the mission, vision, and background of the gallery.

### Built With

* **Frontend Architecture:** HTML5 (Semantic structure)
* **Styling & Design:** Custom CSS3 (Layouts and typography)
* **Interactivity:** Vanilla JavaScript (Timeline animations and form handling)
